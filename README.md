# TyphoonFGR6-NuclearOption-Mod
Eurofighter Typhoon FGR6 mod for Nuclear Option (BepInEx 5). Turns the FS-12 Revoker into a 400,000-triangle Typhoon: fully modelled cockpit with 7 working displays, moving control surfaces, nozzles, landing gear and weapon bay, its own afterburner and engine sounds. Flight model unchanged. Free, non-commercial, source available.
